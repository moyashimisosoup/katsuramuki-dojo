# APP-022｜料理人側から見た左右反転の修正・検証

確認日：2026-10-23 JST。対象は実験ページ `experiments/pose-lab.html`。写真資料や未校正の指関節は変更しない。

## 1. 発見した根本原因

以前のラボでは「左手＝大根・右手＝包丁」という役割定義は正しい一方、配置は左手がモデルX負、右手がX正に置かれていた。`cameras[0]=(113,83,-150)` および `cameras[1]=(0,28,-210)` はともに大根のZ負側から見ているため、**モデルX正は画面左**に投影される。実際の投影を計算すると、左手（大根）が画面右、右手（包丁）が画面左だった。

前のチャットで示した `cameras[0].position.set(-113,83,-150)` という**カメラXだけの反転案は無効**。同じZ負側から見る限り投影の左右向きは入れ替わらない。この案は実装していない。

## 2. 修正内容

- Three.js描画用に `poseRoot` という1個のグループを追加し、**`poseRoot.scale.x=-1`** で幾何形状を表示上の左右へ反転。右利きモデルでは、斜め正面と側面の両方で**画面左＝左手・大根、画面右＝右手・包丁**とする。
- 反転は **大根・包丁・帯・両手の仮支点・切れ刃ガイドの全体**に適用。ラベルだけを入れ替えず、同じ3D状態を維持する。
- UI上の親指・掌ラベルは `poseRoot.localToWorld()` を通して投影し、実際の描画と一致させる。
- カメラのZ負側と切削点の角度は維持。接触部を大根の裏側へ隠さない。独立の物理・ゲーム描画は変更しない。
- 第3ビューは軸方向で手の左右が奥行きに重なるため、**左手／右手の画面上の位置について合格を要求しない**。他の2視点と同じ単一モデルを使い続ける。

## 3. 数値テスト

`tests/pose-lab-model.test.js` に以下を追加：

- カメラからの前方ベクトルと世界の上方向から正しい**スクリーン右方向**を計算する。単なる世界Xの大小では判定しない。
- 接点角 `-85°, -60°, -5°` と、斜め正面・側面の **2カメラ×3角度**で、反転後の左手の投影Xが右手より小さいことを確認。
- 従来配置では反転していたこと、**カメラXを正負だけ入れ替えても不具合が残ること**を逆向きのテストで示す。
- 切れ刃の両端と帯の根元が鏡映後も一致し、円柱側面への半径方向の接触は変化しないことを確認。
- `poseRoot` に全シーン内オブジェクトを収納し、ラベル投影にも同じ変換がかかることをソース検査する。

## 4. 状態を混同しない

これは**画面における左右配置の修正**であり、実物の包丁の刃付・手首回旋・親指の接触・皮むき動作の正確性の認定ではない。モデルの左右をひっくり返したため、のちに本物の和包丁の柄・裏表・左右用刃を導入するときは、器具の左右仕様をあらためて精査する。

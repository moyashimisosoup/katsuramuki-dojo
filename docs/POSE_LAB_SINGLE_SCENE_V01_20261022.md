# APP-022｜単一の3D静止姿勢ラボ v0.1

作成：2026-10-22 JST
状態：**単一姿勢の検証用PoC。写実化・実技姿勢の承認・実機WebGLは未完了。**

## 1. 何を作ったか

- 入口：`experiments/pose-lab.html`
- 描画：`experiments/pose-lab.js`（CDN Three.js 0.180.0。表示だけを担当）
- **唯一の3D座標モデル**：`src/rig/pose-lab-model.js`。既存`src/rig/knife-pose.js`から大根の軸、切れ刃の両端、刃面の四角形、包丁の柄の接続点を計算。
- `tests/pose-lab-model.test.js`。一つの切れ刃に連続する帯の根元、刃面角変更で接点がずれないこと、3カメラが同じシーンを参照することを確認する。
- ページはスマホ幅では3画面を縦配置し、PCでは3画面を横並びにする。斜め正面・側面・円柱軸方向。**カメラが違っても物体を描き直さない**。
- 手は実物と見分けられるリアルな手ではなく、**左右それぞれ「掌と親指の仮支点」だけを抽象表示**。握りの正解という意味ではない。
- 薄片は一枚のメッシュの始端が刃の両端と一致する。曲線、長さ、しなりは**仮形状**。

## 2. 実物との関係

- 観察済み原画：KPHOTO-002, 007, 013, 026。出典と具体的な見え方は[前回の目視記録](KATSURAMUKI_PHOTO_OBSERVATIONS_20261022.md)。
- 具体的に再利用するのは「大根の側面に切れ刃が接する」「薄片が一枚の帯として発生」「左手が大根、右手が包丁」という**可観察な機構の概略のみ**。
- KPHOTO-013の両親指の粗い画素座標は**カメラ校正されていないためこの3Dモデルには投入していない**。
- `tsuji_horizontal` に対応する横保持方式の暫定モデルに限定。縦方向で保持する他の指導方式を不正解扱いしない。
- `contactAngleDeg=-60`、`bladeFaceAngleDeg=0`、半径35／幅50等は **研究観察に基づく測定値ではない**。UI操作でどう見えるか比較するための仮値。画面とコードでは「仮」と明示する。
- 写真を見ただけで刃面の実際の角度を一意に求められない。左右の親指の骨格も未確定。

## 4. 公開と既存コードの境界

- `index.html`、`src/main.js`、`src/view3d/scene.js`、`src/physics/surface.js`を変更しない。
- Pagesでこの独立のHTMLを開けるようにする場合も、本体UI・保存データ・R0物理には影響させない。
- Pages上のHTTP取得に成功してもiPhoneのWebGLが成功したと報告しない。
- ソースはPublic GitHub。外部の実物写真をそのまま埋め込んだりGitHubへコピーしたりしない。出典元へのリンクのみ。

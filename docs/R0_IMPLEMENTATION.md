# R0 局所切削コア・操作可能な可視化

APP-022 | 2026-10-18 | 実装段階：R0 幾何学的材料除去

## 実装
- `src/physics/surface.js`: 大根の円周方向の区分に対し、刃がその途中に触れた場合は角度区間を分割して削除。幅方向12レーンで半径を独立管理。
- `cutSweep` により、刃の絶対半径と幅方向の傾きから接触部分だけを局所除去。大根の逆回転・停止・空振りでは材料を削らない。
- `dV=0.5*(r_old²-r_new²)*dTheta*dZ` を積算し、残材料と除去体積を照合。
- 全幅でむけた帯と、部分幅の削り屑を区別し、上端・下端の厚さと素材体積を記録。
- `index.html` で大根・包丁・帯の模式図と表面展開ヒートマップを表示。送り・傾き・回転速度を操作し、30秒の動作を試せる。

## 未実装・限界
- 切削抵抗・弾性/粘弾性・摩擦・帯の柔軟体運動・破断は未実装（R1～R3）。
- シート状の帯は幾何的な区間記録。描画上の曲線は模式図で物理的なPBD/XPBDではない。
- 接触中の刃先半径の軌跡は各切削小区間の中点で近似。角度方向の区画は刃が一部分だけ触れても区間分割を行う。
- 実際の物性値がないため game-mmで表現。現実の料理技能・材料力学の再現精度を保証しない。
- 体積の保存は幾何モデル内部での検算。実物の形状や薄片が完全な連続シートを形成する保証とは別。
- `cutSweep` は状態を破壊的に更新するAPI。初回は切り始めのタブがあるものとしてモデル刃を初期半径34.5にセット。
- 無限モードのメモリ上限、実機Safari/Android、2指操作は未実施。

## 検証
`npm test`（Node.js 20以上）で切削の12条件を試験する。静的ページはES Modulesを使用するため、HTTPサーバー上で`index.html`を開く（file://直接は不可）。

### 既知の限界
1. 大根のR0局所切削状態は**角度区画の中心点**でGPUに描画する。物理コアでは区画内の切削を厳密管理しており、GPU表示は軽量化のため近似。細い欠けが見えにくい場合がある。
2. 帯はR0の`currentRibbonLength`と幅`width`に基づくが、垂れ下がりは**仮曲線**。物理的な重力・曲げ・ねじれはR2で実装する。
3. 包丁は3D幾何に沿う簡略モデルで、磨き面や実際の刃物の寸法を再現したアセットではない。左手・右手モデル未実装のため、浮いた大根を検証用に表示する。正しい実技指導の映像ではない。
4. THREEの読み込みは外部CDNに依存。オフラインやネットワーク制限下では2D代替へ戻る。将来のビルド・同梱化を検討。
5. このセッションのローカルブラウザはネットワーク管理制限によりHTMLとThree.jsの実描画確認ができなかった。**Nodeの数値テスト通過を実際のWebGL画面確認と混同しない**。
6. GitHub Pages公開は2026-10-19に承認済み。配信workflowをmainへ保存しCIは成功したが、Pagesサイト未有効化の404でデプロイ失敗。公開は未完了。詳細は `docs/PAGES_RELEASE_20261019.md` を参照。

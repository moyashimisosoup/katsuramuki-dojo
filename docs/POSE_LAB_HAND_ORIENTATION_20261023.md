# APP-022 | 姿勢ラボ・右利きモデルの左右表示 v0.2

更新：2026-10-23 JST。対象は独立ページ `experiments/pose-lab.html` のみ。

## 目的

ユーザーから「左右はこの向きで合っているか」の実機レビューを受けた。現行3Dモデルの手の造形は球・棒の仮支点であり、**実演者の左右と画面上の左右を混同しやすい**。見えている画面左の手が必ず左手とは限らない。手の役割を明示し、比較時の誤認を防ぐ。

## 今回の変更

- **左手（茶色）＝大根を保持・回す、右手（青色）＝包丁を操作する**。右利きという前提だけを固定し、関節や握りの正確さは承認しない。
- 上部に役割の凡例を常時表示。色のみで区別せず、文字「左手・大根」「右手・包丁」を併用。
- 各カメラで、同一モデルの `leftHand.palm` と `rightHand.palm` をスクリーン座標に投影して役割ラベルを追従表示。位置が近い場合にはラベルを上下に分散させる。
- **大根の軸方向ビューではX軸の前後が同じ平面へ重なる**。役割ラベルを左右に分けて表示し「奥行きに重なる」と明記。これを実物の左右の向きとは解釈しない。
- 「左右の支持点を表示」チェックを切ると、その支点ラベルも隠す。スマホでは3視点を縦並びに維持。

## 検証と未完了

- `tests/pose-lab-model.test.js` に右利きモデルの左右の役割、表示ラベル、カメラ投影、軸方向の注記を追加。
- モデル座標の「左右の役割」と、実際の料理人の親指の立体的な形が一致するかは**別の検査**。KPHOTO-013等の写真は画素座標を一部記録しただけで、実寸やカメラ校正は不明。3Dの手指姿勢の正式な採用は0件。
- 自動テスト合格、Pages配信、Safari WebGL実機操作はそれぞれ独立して確認する。
- 既存ゲーム `index.html` と `src/main.js`、動作コア、配信先の位置は変更しない。

## 実機で確認すること

iPhoneで[3D姿勢ラボ](https://moyashimisosoup.github.io/katsuramuki-dojo/experiments/pose-lab.html)を開き、(1) 3視点に左手・右手ラベルがある、(2) 茶色が大根側・青色が柄側に対応する、(3) 切削位置スライダーを動かしても役割が入れ替わらない、(4) 「左右の支持点を表示」をオフにするとラベルも消える、(5) 軸方向で奥行きの重なりが説明されている、を検収。

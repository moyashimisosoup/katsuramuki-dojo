## 3. 要素別の判定規格

| 区分 | 最初の検査質問 | 判定不合格の典型 | 保留にする場合 |
|---|---|---|---|
| 作業環境 | 大根は手で支えられているか | 台上に固定し輪切り | まな板が背景に写るだけ |
| 大根・軸 | その選択方式の保持軸か | 同一カット内で軸が突然転換 | A/B方式をまだ選んでいない |
| 左手（右利き） | 指腹の支点と親指の回転が成り立つか | 指が貫通・保持していない | 親指が隠れている |
| 右手（右利き） | 柄と親指を保持し刃が安定するか | 包丁が浮いている／非人間的な関節 | 手首が画角外 |
| 接触線 | 切れ刃が**側面**に触れているか | 円柱の端面を輪切り | 刃の裏側が見えない |
| 刃面 | 切れ刃と面を区別した姿勢が説明できるか | 切れ刃なしで帯が発生 | 写真1視点しかない |
| 動作 | 回転と包丁の上下滑走が共存するか | 包丁を径方向に押し込むだけ | 静止画では動き不明 |
| 帯 | 連続した面が刃と円柱の間から出るか | 空中から生える／細い麺 | 帯がまだ出ていない開始時 |
| 厚み | 上・中央・下の厚みに一貫性があるか | 帯幅・半径の値が見た目と矛盾 | 実測できない |

**不合格 / 合格 / 不明**の三値を採用する。不明は不合格にしないが、3D制作への正式承認には使えない。資料の中に立て持ち例があることを理由に、横持ちのAを自動棄却しない。

1. **方式Aに限って**辻調実演から1人・1回・連続数秒のシーンを選択。対象は切り始め→5〜10cmの帯まで。確認前に1秒ごと等のタイムスタンプを捏造しない。
2. 対応する元の写真 KPHOTO-002 / 007 / 013 / 018 / 019 のうち**実際に切れ刃が見える**ものを選定。写真URLは `REAL_KATSURAMUKI_PHOTO_REFERENCES_30.md` を参照。**現時点では5候補の採否を未決定**。
3. 大根軸、左右親指、包丁柄、切れ刃線、分離点を、画像上の点や線と3Dの接触モデル `src/rig/knife-pose.js` の座標に紐づける。初期の接触角 `CONTACT_ANGLE` はゲーム仮値であり測定値として流用しない。
4. まず前面/側面/軸方向の**一つの3Dシーン**から3視点を出力。1枚ごとに別の生成AIに想像させず、同じ3D座標で整合を検査する。
5. 手・接点を3回独立にレビューし、重大な不一致が無い場合に限り写実材質の追加へ移る。最終姿勢採用はユーザー確認が必要。

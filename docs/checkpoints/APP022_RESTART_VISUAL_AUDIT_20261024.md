## 4. 独立pose-labの再現可能なコード上の不整合・リスク

対象: `src/rig/pose-lab-model.js` の初期値（`contactAngleDeg=-60`、`bladeFaceAngleDeg=0`、`cutDepthMm=0.5`）。`src/rig/knife-pose.js` の計算を使用。

- 大根はX軸 `[-25,+25]`、半径35モデルmm。
- `rightThumb=handleAnchor+[-19,-2,-2]` なので、親指の中心Xは **+40**。円柱の軸方向端 +25 より15モデルmm外側。
- 初期値の `rightThumb ≈ [40, 39.50, -17.88]`、中心からのYZ半径 ≈43.36。円柱の有限な側面に対する最短幾何距離は約17.17モデルmm（モデル上で計算された値で、実写の測定値ではない）。
- `leftThumb ≈ [-19,22.20,-26.44]` は円柱表面付近。現状の左右親指は**同じ刃付近の厚み観察機構を再現していない**。
- `rightPalm = handleAnchor+[15,-10,6]`、`leftPalm=leftThumb+[-22,-20,5]` はいずれも仮支点。掌・親指間は球と棒1本だけで、指4本、関節、手首、握りの接触は存在しない。
- `poseRoot.scale.x=-1` は**描画全体の鏡映**。PR #18は画面内の左右を修正したが、将来の右利き専用片刃形状を導入するときは表裏・実物の刃付を別途チェックする必要がある。
- `ribbon` の始端が刃と一致することは幾何的に確認済み。ただし帯の進む向きと切削点の実演写真校正は未完了。

**解釈**: 右親指の位置と人間の手の造形に構造上の改善余地がある。これは独立pose-labのコード監査による所見であって、ユーザーが以前見た画面の不具合原因を確定した証拠ではない。R0にはこの左右の手のモデルは接続されていない。

# APP-022｜R0包丁の刃面と柄の接続修正 v1

2026-10-23 JST。対象：**R0 Three.js 3D表示のみ**。正本 `moyashimisosoup/katsuramuki-dojo`。

## 発見した問題

もとの `src/view3d/scene.js` は刃面を `knifeShape()`、柄を `handleStart` と別の数値式で描画していた。刃面の右上端は大根軸のX正側 `width/2`、柄の長手方向の端は `width/2+3+18-31/2 = width/2+5.5` なので、刃面との間に**約5.5モデルmmの隙間**ができていた。さらに柄のY/Zオフセットと刃面の仮リフト量も別々だった。

こうした隙間は、実写の包丁を再現する以前に、モデルの剛体としての一体性を損なうため修正する。

## 実施した修正

- `src/view3d/geometry.js`に純粋関数 `buildKnifeDisplayData(daikon,bladeRadius,tilt,...)` を追加。
- 既存 `bladeEdgeEndpoints` から刃元と切先を求め、刃面の右上隅 `faceUpperEnd` と **`handleStart` を厳密に同一の3D座標**として計算。
- 柄の中心は両端の中点、長さは `handleLength` で一貫させる。Three.jsの円柱メッシュの端が刃面に接する。
- `scene.js`に重複していた刃・柄の位置式を削除し、この単一データから両方を描画。
- 既存の帯の始端と切れ刃2端点の一致は維持。R0の半径・体積・材料除去量、ゲーム操作・スライダー、3D姿勢ラボは変更しない。

## 検収と限界

`tests/geometry3d.test.js`に3テスト追加：

1. 刃の傾き5パターン・刃の半径4パターンで、刃面端と柄端の差がゼロ。
2. 刃の傾き3パターンで、帯の始端左右2点と刃の始端左右2点が一致。
3. 無効な展示用寸法を拒否し、物理状態（`removedVolume`）を変更しない。

寸法（刃の高さ・柄の長さ・大きさ）、実際の和包丁の刃付け・柄への差し込み構造、左手・右手の指、切削抵抗、布状の薄片の物理変形は**すべて未測定・未実装**。技法として合格したと主張しない。

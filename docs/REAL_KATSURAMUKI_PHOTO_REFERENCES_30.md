# 実物の桂むき写真・30点参照リスト（APP-022）

収集日：2026-10-20 / 状態：**出典ページで画像URLを特定した参照候補30点。全部を見て角度を確定したわけではない。**

## 方針

- AI生成物・再生成画像は含めない。画像を保持する出典ページと、そこで読み取れた画像URLを対応づける。
- **画像の転載・GitHubへの画像ファイルの保存は行わない。** ここに掲載するのはリンクと観察用途のみ。各出典の著作権・商用利用条件・ホットリンク可否は別に確認する。
- 同じ写真のサイズ・言語違いは重複として収録しない。複数の写真が同じページにあることは明記する。
- 「検索プレビュー確認」は写真の見た目を一次確認した印。「出典ページ確認のみ」は画像の個別角度・用途の追加目視審査が必要であることを示す。
- `画像を開く` は別サイトの画像URLへの直接リンク（別途HTTP/ブラウザの画像単体取得検証は未完了）。`掲載元` はその画像の出典ページ。
- 収録数 **30画像 / 12出典ページ**。写真の「角度に関する採用認定」は**0/30**。今後、刃先と包丁の面の位置・手の姿勢を確認して認定する。
- 桂むきに関係した準備や結果写真も含むため、**30点すべてが包丁角度を示す写真ではない**。

## 3D再現の評価チェック

- 切れ刃の**接触線**と、大根の軸方向が整合しているか。
- 刃の**面が向く方向**と、その刃の**接触線**を混同していないか。
- 大根を支える指と包丁を支える親指・柄の位置が現実の実演と一致するか。
- 帯が細い糸ではなく**大根の幅を持つ薄い面**として接触部から連続しているか。
- 大根の回転・包丁の滑走・帯の発生を同じタイムラインに置けるか。
- 写真1枚の投影角度は3D姿勢を一意に決めない。別方向の写真・実演動画と照合し、選定根拠を残す。

## 次にやること

1. 30候補のうち接触線が明確な写真を10点ほど別視点で目視判定し、最終的な「姿勢基準写真3〜5点」を選ぶ。
2. 複数の実例が矛盾する場合は技法・包丁の種類・撮影方向の違いを記録し、平均角度を無理に作らない。
3. 3D静止ポーズを同じ視点で比較し、刃先・刃面・両親指の対応づけを承認してからリグ付きGLBの制作を始める。

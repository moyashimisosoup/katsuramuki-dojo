# APP-022 | ストローク位相モデル R0.5（公開画面には未接続）

作成日：2026-10-20 / 技法基準：京都調理師専門学校の2025年公式実演の自動字幕。**映像フレーム未検証・実寸と角度は未校正。**

## 目的と実測可能な範囲

[先行監査](KATSURAMUKI_VIDEO_MOTION_AUDIT_V1.md)で、現行の大根常時回転と指導上の「上げ動作で大根を回し、戻しでは回さない」の違いが判明。既存R0局所切削コアを維持したまま、包丁の往復を**独立した運動**として記述する。

ソース：`src/physics/stroke-cycle.js`、テスト：`tests/stroke-cycle.test.js`。公開中の `src/main.js` と `index.html` はこのPRでは変更しない。

## 状態モデル

| データ | 意味 | 根拠区分 |
|---|---|---|
| `phase` | `upstroke` または `return` | 字幕に基づく分類 |
| `strokePosition01` | 0～1の仮想上下位置 | **ゲーム上の仮座標** |
| `deltaAngleRad` | 上げ局面の大根回転量、戻しはゼロ | 字幕に基づく位相、量は仮設定 |
| `upDurationSeconds=0.8` | 上げ動作時間 | **未測定の仮値** |
| `returnDurationSeconds=0.6` | 戻し動作時間 | **未測定の仮値** |
| `upAngularSpeedRadPerSecond=1.2` | 上げ局面回転速度 | **未測定の仮値** |
| `cuttingCandidate` | その位相で材料除去を計算しうる目印 | 刃と大根の接触・荷重の真偽は未確認 |

数値は実演の所要時間・手の移動距離・切削力を**測定した値ではない**。実映像からの校正が必要。選んだ指導方式以外へ一律に適用しない。

## 安全な連動方法

1. 独立運動コア `advanceStrokeCycle` は状態と、位相境界で分割済みの小区間（`segments`）を返す。
2. 未来のR0連動層は `segments` の `deltaAngleRad > 0` についてのみ `cutSweep` を呼ぶ。**戻し動作では0角のcutSweepを呼ばない**。R0の現在の仕様では0角入力時に帯の連続表示長がリセットされてしまうため。
3. 包丁面の3D姿勢、親指の保持、刃の上下振幅は**この純粋な運動関数が勝手に決めない**。後で写真の対応点から別途接続。
4. `cuttingCandidate` を「刃が物理的に接触した」「切断力が正しい」と混同しない。R1の摩擦・力学は未実装。
5. 実物資料による受入前は**検証用featureのみ**。GitHub Pagesの操作画面は現行状態を維持する。

## テスト基準

- 上げ時のみ正方向回転し、位相が転換する
- 戻し時の回転量ゼロ、上げ開始まで位相遷移
- 1フレームで上げ・戻し境界を跨いでも区間分割して正しく累算
- 停止中は包丁・大根とも進行しない
- まとめて進めた場合と微小刻みの場合の計算が一致
- 既存 `cutSweep` と試験的に連携し、**戻し時に切削体積は増えず、材料体積保存も成立**
- 無効な時間・速度・位相を拒否
- 描画、タイミング、UI、外部サービスに依存しない

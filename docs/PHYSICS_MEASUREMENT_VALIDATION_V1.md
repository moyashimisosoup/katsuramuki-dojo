## 1. データの信頼区分

| 区分 | 内容 | 使用可能範囲 |
| --- | --- | --- |
| E0 Published | 論文等で公開された技法・寸法・所要時間 | 限定条件つきの比較基準、データ出典の明示 |
| E1 Observed | 公式画像・動画から目視した動作 | 定性的な機構設計、映像が編集されていない場合のみ相対的動作 |
| E2 Measured | 適正な許諾のもとで撮影・計測した大根・包丁・剥き帯の測定値 | 具体的な動画解析による幾何学・軌道の校正 |
| E3 Instrumented | 力・トルク・材料試験・刃の位置を計測した試験 | 力学モデルのN/J/Pa等の校正、測定系の誤差評価が必須 |
| H Hypothesis | 物理的に合理性があるが未測定の仮定 | 無次元係数を持つ試作のみ。実測値と混同しない |

オープンデータでない動画や研究の原画像は公開リポジトリに複製しない。出典URL、許諾状態、観察メモ、必要なら自作した抽象化データだけを記録。顔、音声、人物情報、学校内部資料等の扱いは別途判断。

## 2. 最初に確保する観察値

A. 大根：初期半径(mm)、高さ/桂むき幅(mm)、円柱の傾斜、最終半径。
B. 刃：包丁の種類と刃の外形、接触幅、刃先の軸に対する傾き(度)、上下ストロークの周期と振幅、刃先の径方向変化。
C. 運動：回転角θ(t)、角速度ω(t)、滑走速度、手の位置の動きと時間差。
D. 結果：累積長さL、むいた帯の上下端厚さt_top(s)/t_bottom(s)、幅W(s)、途中の切り込みや破断位置。
E. 可能なら：力・トルク、刃先摩耗、水分率、食品硬さ・弾性率・破断特性。ただし危険な自前の測定を前提にしない。

研究時の絶対的な記録と、ゲーム内スケールを分ける。画面上の見かけ速度だけからmm/sを確定しない。

## 3. データセット1：公開研究の検算例

加賀谷・加藤（2023） DOI https://doi.org/10.20557/00003490

初期参照（原論文の条件に限定）：
- 熟練者Tの剥き帯30cm区間、下側平均0.71±0.15mm / 上側平均0.85±0.32mm → 上下単純平均0.78mm。
- 非熟練者C：下側0.70±0.25mm / 上側0.76±0.24mm。
- 非熟練者B：下側2.69±1.53mm / 上側1.68±0.63mm → 上下平均約2.19mm。
- 30cmに必要な時間の例：熟練者107秒、非熟練者140〜256秒。
- 熟練者1名・非熟練者6名の小規模事例であり、専門家の普遍的パラメータでも、すべてのユーザーが達成すべき値でもない。

解析する観点：
1. t_topとt_bottomを**それぞれ**再現し、平均だけで同一視しない。
2. 厚さの標準偏差と上下差を独立して算出する。
3. 30cm当たり時間は練習・ゲームの速度係数を決める資料にはなるが、30秒のアーケードゲームと現実時間を無断で一致させない。
4. 研究の画像から見えるフォームの違いは指標として検討するが、実測不可能な加速度や力は推測値と区別する。

## 4. データセット2：動画から計測するとき

実物動画を確認したうえで、測定可能な映像に限り：
1. 可視の回転角マーカーでθ(t)をトラッキング。見えない角度区間は補間の不確かさを記録する。
2. 包丁の刃先と大根の軸をフレームごとに合わせ、刃の上下・横方向変化の相対値を得る。
3. 映像内に既知寸法があるときだけ絶対寸法へ変換。手などの大きさから決めつけない。
4. 複数カメラがないと奥行き傾斜が分からない点、動画編集や手ぶれ、露出による見え方を記録する。
5. 帯の曲がり・垂れ下がりは写真とアニメーションを同条件で比較する。ただし静止画だけで曲げ剛性を確定しない。

最初の動画評価は目視で十分。危険な包丁作業の再現・本人の新規撮影は前提としない。動画解析にOCRは不要。

## 5. データセット3：将来の力測定（専門設備がある場合だけ）

力学校正用の必要計測：
- 刃にかかる接線方向の反力N、包丁押し込み力、滑走力。
- 実際の送り/刃先角、食材の温度・鮮度・水分、包丁の鋭さ。
- 剥き帯の引張強度・破断ひずみ、曲げ変形と垂れ方。
- 力・変位の同期サンプリングとセンサー校正情報。繰返し試験の平均とばらつき。

安全な実験系を整えた調理・工学の専門者と協働する。データ取得のための危険な自作包丁治具や計測を勧めない。

## 6. 物理パラメータ台帳の候補カラム

各パラメータに以下の記録をつける：
- parameter_id / physics_module / symbol / numeric_value / unit / source_id
- evidence_level (E0/E1/E2/E3/H) / measured_at / material_conditions
- uncertainty / validity_range / calibration_method / review_status
- note / modified_in_commit

未計測なら numeric_value=null とし、別に game_tuning_value を保持する。公開の数値が確定していない大根の弾性率Eや破断強度σcを仮の物理単位で埋めない。

## 7. 校正のゲート

V0：再現可能な円柱の接触・材料除去。質量と体積の保存は数値的誤差の範囲内。
V1：刃の傾きに応じた帯の上下厚さ差を再現。厚さデータは両縁を別管理。
V2：力・摩擦の式は単位整合・符号・極限値を検査。ただし「現実の反力を再現」と言わない。
V3：生成帯の形は重力・曲げ・引張に対して安定し、厚さの異なる帯で質的な違いが出る。
V4：破断条件は場所・入力・応力/ひずみから説明可能。
V5：外部測定値の誤差帯を使った比較。専門校正がない場合は「ゲーム用近似物理」として公開可否を判断。

## 8. 作業と責任の境界

- **今回**：仕様・実験計画の文書化のみ。材料試験、フレーム計測、コード実装、外部公開は未実施。
- 計画への追記時は初期資料を上書きせず、新たな根拠と変更理由を残す。
- 必要に応じて最初の測定表は公開済み論文の数値を**出所・条件付き**で再入力する（転載と再利用の条件に従う）。
- ゲームの上達判定はあくまでシミュレーター内の仮想技能。実際の刃物取扱技能を認定しない。

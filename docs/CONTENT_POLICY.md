# 図鑑とゲームデータの方針

## 出典区分
- `fact`: 資料に支えられる説明の初稿。カードごとに出典キーを付ける。
- `theory`: 語源などの諸説。断定せず、「説」と明示する。
- `unknown`: 特定・検証できていない事項。
- `game_model`: 画面演出や擬似物理。歴史・現実の包丁技術そのものを保証しない。

カードの `review_status: draft` は内容の専門校閲・一次資料確認が未完了という意味。データ形式のテストに合格しても事実確認にはならない。

## 文体
子どもにも読める自然な日本語。ただし史料がない内容は想像で補わない。考案者・発祥年代は安易に特定しない。包丁の危険な実技指導ではなく文化とゲーム体験に徹する。

## 外部の扱い
参考文献のURLはリンクとして扱う。本文・写真・画像・ロゴ・動画・独自の図解を無断で転載しない。出典URLの生存確認は後工程。ライセンスは未決定。

## 修正の手順
1. source IDとURLの記録を確認する
2. 元記事を読んで事実と説を分類する
3. カードの文言を短く独自の表現にする
4. 必要に応じて専門家・現場の解釈を併記する
5. 誤りの修正はGitHubコミットで追跡する

これはゲーム内コンテンツの編集基準であり、出典での裏付けを得た保証ではない。
